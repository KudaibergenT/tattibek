# InsuMap — карта мест инъекций инсулина (MVP)

Веб-приложение, которое помогает людям на инсулинотерапии чередовать места уколов и не колоть в одну точку. Частые уколы в одно место приводят к липогипертрофии и непредсказуемому всасыванию инсулина.

> **Демонстратор концепции для хакатона.** Не является медицинским изделием, не рассчитывает дозы и не заменяет рекомендации врача.

## Возможности

- Карта тела (вид спереди и сзади) с 10 зонами инъекций: 4 сегмента живота, бёдра, плечи, ягодицы.
- Каждый укол сохраняется как точка. Цвет зон и точек меняется плавно от красного к зелёному в зависимости от давности уколов.
- Правило ротации: новый укол не ближе 2,5 см к уколам в той же зоне за период (по умолчанию 14 дней). Таймеры показывают, когда зона снова свободна.
- Рекомендация следующего места с учётом отдыха зоны, чередования областей и сторон тела и типа инсулина.
- Справочный блок «Время до еды» с таймером после укола.
- Статистика за 7 дней: число уколов, процент соблюдения ротации, самая частая зона.
- Отчёт для врача с печатью или сохранением в PDF.
- Демо-режим: реалистичная история за 18 дней в один клик. Ваши записи на это время сохраняются и восстанавливаются при выходе.

## Запуск

Откройте `index.html` в браузере. Сборка и сервер не нужны, данные хранятся в `localStorage` браузера.

## Технологии

Один HTML-файл: HTML, CSS и JavaScript без зависимостей, шрифт Onest из Google Fonts. Работает офлайн, в этом случае используется системный шрифт.
